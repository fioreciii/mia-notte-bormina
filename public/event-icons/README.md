# Procreate event illustrations

Export transparent WebP or PNG files at 512 × 512 px using these names:

- `food.webp`
- `music.webp`
- `show.webp`
- `kids.webp`
- `culture.webp`
- `shopping.webp`

Keep the important drawing inside the central 80% so it remains legible in
small cards and map markers.
