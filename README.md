# La mia Notte Bormina

Mobile-first itinerary planner for the Notte Bormina 2026. Visitors can filter
54 stops, select any combination, choose a starting point, generate a
time-aware walking route, share it and add it to their calendar.

## Languages

Italian, English, Spanish and German.

## Local development

```bash
pnpm install
pnpm dev
```

The app is built with Next.js and does not require a backend.
