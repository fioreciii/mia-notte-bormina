# La mia Notte Bormina

Mobile-first itinerary planner for Notte Bormina 2026 in Bormio, Italy.
Visitors can explore 54 official stops, choose the experiences they want and
generate a time-aware walking route through the historic centre.

## Features

- Interactive illustrated map with all 54 official stops
- Filters for food, music, shows, children, culture and shopping
- Optional current location, map pin or town landmark as a starting point
- Walking-route optimisation that considers scheduled performances
- Shareable selections stored in the URL
- Calendar export for individual events or the complete route
- Responsive light and night themes
- Italian, English, Spanish and German interfaces

## Design

The interface uses ABC Arizona Mix and ABC Arizona Sans as variable web fonts.
The typefaces are included with permission from the project owner. Their
copyright and licensing remain with Dinamo.

The illustrated map and event information were digitised from the official
public programme. This is an independent portfolio project and is not an
official Comune di Bormio website.

## Languages

Italian, English, Spanish and German.

## Local development

```bash
pnpm install
pnpm dev
```

The app is built with Next.js, React and vinext. It does not require a backend.
